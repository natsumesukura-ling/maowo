# 新猫窝的想法

> 绫和 AI 一边聊一边记的地方。**这是方向，还不是施工图**：没写进「定了的」就不要动手做。
> 开始记：2026-11-10。每聊定一点就更新这里；绫说「给我看看记了什么」就念这一页给她听。
> 绫想法多、会变、一次说不全，这很正常。一次只问她一个问题，从已经发生过的具体事情问起。

## 为什么要大改

猫窝最初是「一群小机陪绫玩狼人杀」的游戏大厅，猫是来坐的客人。做着做着，绫真正想要的变成了
**「可以陪她玩狼人杀的酒馆」**（像 AI 酒馆那样的角色扮演，为主；游戏是点缀）。
代码和页面还是按旧的主次摆的，所以她觉得别扭，想大改：页面美化重做，一部分逻辑框架重排。
不是完全推倒：数据（猫的记忆、人设、世界书、帖子、存档）都留着，功能也大多留着。

## 定了的

- **酒馆为主，游戏是点缀。** 游戏区已经从主要挪到次要。
- **角色扮演时，沉浸感最重要。**
- 导航栏「猫们」排第一个（已做：猫们、游戏、聊天、我的）。
- 回话要看得见它在写（已做：私聊流式输出、断了留着、空了说原因、「接着写」）。
- 讨论和记录放在这里（看得见代码的 AI 这边）；画示意图、找感觉可以找 ChatGPT，图发过来照着做。

- **「猫们」页一眼看过去只有角色卡，猫是主角。** 钥匙、面具、预设、世界书、搬进来 / 移出猫、总开关这些，全部收进右上角一个小按钮点进去的「设置页」，主页面上不留。
- **美化由绫自己换**：设置里加一个「美化」页。
  - **主题可以存好几套（起名字），每只猫选一套；没选的用默认那套。** 背景是主题里的一项，所以「每只猫各自一张背景」就是给它换一套主题，不单独做。
  - 输入框、导航栏可以选水玻璃 / 毛玻璃样式。
- **美化要像 Tavo 的「主题」那样自由度高，样样都能自己切换**（绫 2026-11-10 发了 Tavo「编辑主题」的 7 张截图当例子；只参考它**能调什么**，页面长相不照抄）。它能调的：
  - 主题有名字（例：「水蓝」），右上角随时「预览」，底部「保存」。
  - 背景：图片、图片透明度、底色（颜色 + 透明度）、底部遮罩（自动取色）。
  - 输入框：颜色 + 透明度、高斯模糊、圆角、按钮颜色、文字样式、占位符颜色。
  - 气泡：列表样式、消息样式（气泡 / 别的）；角色气泡和用户气泡各自的位置（左 / 右）、颜色 + 透明度、高斯模糊、圆角。
  - 字体：角色和用户各自的文字样式；**旁白高亮**（认 `*…*`、`(…)`、`（…）`，可以选显示时要不要留符号，单独的文字样式）；**引用高亮**（认 `“…”`、`"…"`，同上）。
  - 头像：私聊 / 群聊里，角色和用户各自要不要显示头像、头像圆角、要不要显示名字。
  - 自定义 CSS，加一个放图片资源的地方。
- **主题只管聊天窗口；其他页面（猫们、游戏、帖子、我的）另有一个「全局外观」**：全局背景、导航栏的玻璃效果在那里调，和猫的主题分开。
- **一条「主线」+ 任意多段「故事」**（绫说两种都想要一点；AI 提的方案，绫接着回答了里面的问题，当作点头了，她说不对再改）：
  - 主线：现在那个窗口，一只猫一条。住在猫窝里的它：小本本、前情提要、游戏、发帖、闹钟、被评论，都只在主线。
  - 故事：同一只猫可以开很多段，各自独立的窗口、聊天记录、前情提要，互相不知道；开的时候可以写开场设定或选角色卡的开场白；故事里不用工具、不会被游戏叫走；每段可以选自己的主题。
  - 现在的「番外」并进来：番外就是从主线岔出去的一段故事。结束时的三个选项留着（悄悄删掉 / 告诉主线一句 / 留着接着演）。可以借这个把 `ova_from` 那套换掉。
  - **开一段故事 = 绫给一段背景设定或指令，它就开始写**（和现在的番外一个逻辑，它先开口）。不是摆两个「认识 / 不认识」的大按钮。
  - 开场的地方有一个小开关「**带上主线的记忆**」，**默认开着**（带小本本和前情提要进去）；关掉就是只带人设、真的不认识她，也更省额度。
  - **故事默认一直留着**，随时回去接着演，主线不知道；没有非做不可的「结束」动作。三件事随时能做：接着演 / **告诉主线的它（给的是一段「摘要」，不是一句话，免得主线的它看得莫名其妙；绫写或它自己总结）** / 删掉整段。

- **帖子区留着，逻辑不变**（小秘密、图片、投票、评论都保留）；猫想发帖还是在那里发（主线的它）。
- **存档照旧，位置不变**（在「我的」页里）。
- 角色卡（每只猫的卡片）长什么样：绫会让 ChatGPT 生图，照图做。图没来之前不动。
